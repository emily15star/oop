## Унарност и бинарност на оператори во C++

Операторите во C++ се делат според бројот на операнди врз кои дејствуваат на унарни и бинарни оператори.

Унарни оператори – дејствуваат врз еден операнд.

Примери:
- ~ – модул на комплексен број (во нашиот пример).
- ! – логичко НЕ.
- ++ – зголемување за 1.
- -- – намалување за 1.
- - – промена на знакот (унарен минус).
Бинарни оператори – дејствуваат врз два операнди.

Примери:
- + – собирање.
- - – одземање.
- * – множење.
- / – делење.
- % – остаток при делење.
- == – еднаквост.
- != – нееднаквост.
- <, > – споредување.
Преоптоварување на оператори во класа и надвор од класа
Кога операторот се дефинира внатре во класата, тој е член-функција на класата.

Кај бинарните оператори се прима еден аргумент, бидејќи првиот операнд е самиот објект (this), а вториот се прима како параметар.
Кај унарните оператори не се прима аргумент, бидејќи дејствуваат само врз објектот за кој се повикуваат.

Кога операторот се дефинира надвор од класата, тој не е член-функција и затоа нема пристап до this.

Кај бинарните оператори се примаат два аргумента – двата операнди.
Кај унарните оператори се прима еден аргумент – објектот врз кој дејствува операторот.

**Еве код кога би биле надвор од класата:**


```
CPX operator+(CPX l, CPX r) {
    return CPX(l.re + r.re, l.im + r.im);
}

CPX operator-(CPX l, CPX r) {
    return CPX(l.re - r.re, l.im - r.im);
}

CPX operator*(CPX l, CPX r) {
    return CPX(l.re * r.re - l.im * r.im,
               l.re * r.im + l.im * r.re);
}

CPX operator/(CPX l, CPX r) {
    float imenitel = r.re * r.re + r.im * r.im;

    return CPX((l.re * r.re + l.im * r.im) / imenitel,
               (l.im * r.re - l.re * r.im) / imenitel);
}

float operator~(CPX z) {
    return sqrt(z.re * z.re + z.im * z.im);
}
```
