# Filesystem – Private and Public

Оваа задача е продолжение на претходната задача за File System. Функционалностите остануваат исти, но разликата е во начинот на кој се организираат податоците и функциите со помош на `private` и `public`.

Како претходната задача, оваа е слична и нема многу да ја менуваме но разликата е во тоа што private значи дека од main() не смееме директно да пишуваме f.name.
public значи дека може да повикаме f.setName("X").

Функцијата setName() има пристап до name, бидејќи е дел од истата класа.Ќе видиме во следниот код...

## Private и Public

- `private` – податоците не можат директно да се менуваат или да им се пристапува надвор од класата.
- `public` – функциите можат да се повикуваат надвор од класата.

На пример:

```cpp
class File {
private:
    string name;

public:
    void setName(string n) {
        name = n;
    }
};
```

Бидејќи `name` е `private`, не можеме директно да напишеме `f.name = "X"` во `main()`.

Наместо тоа, ја повикуваме јавната функција:

```cpp
File f;
f.setName("X");
```

Функцијата `setName()` може да пристапи до `name`, бидејќи е член на истата класа.

## Задачи

Во оваа домашна се имплементирани следниве функционалности:

**0.** Спречување создавање датотека или директориум со исто име и екстензија во истиот директориум.

**1.** При печатење на директориумот се прикажуваат и содржините на сите негови поддиректориуми.

**2.** Имплементација на функцијата `Up()`, која го враќа родителскиот директориум. Доколку не постои родител, се прикажува `/(root)`.

**3.** Имплементација на функцијата `Find()`, која пребарува датотека или директориум во зададен директориум, вклучувајќи ги и неговите поддиректориуми.

**4.** Измена на функцијата `DirectorySize()`, така што во вкупната големина ќе бидат вклучени и сите поддиректориуми.

Дополнително, задржана е и функцијата за преместување датотеки (`moveFile()`) од претходната задача.
